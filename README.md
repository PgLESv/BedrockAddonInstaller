# Minecraft Bedrock Addon Installer

Ferramenta web para organizar addons do Minecraft Bedrock Edition.

## Funcionalidades

- Upload de multiplos arquivos (.mcpack, .mcaddon, .zip, .tar.gz, .7z)
- Gerenciamento de mundos (.mcworld)
- Separacao automatica de Behavior Packs e Resource Packs
- Geracao de arquivos de ativacao
- 100% no navegador

## Como Usar

1. Abra o index.html no navegador
2. Arraste arquivos para a area de upload
3. Clique em Processar Addons
4. Baixe o ZIP organizado

## Deploy no GitHub Pages

1. Crie um repositorio no GitHub
2. Faca push dos arquivos
3. Ative em Settings - Pages - Branch: main

## Notas

- Evite .rar (suporte limitado) - converta para .zip
- Limite: 3GB por arquivo, 200 arquivos
