🌍 Tutorial: Gerenciando Addons de um Mundo

Importante: Quando você envia um mundo (.mcworld), a ferramenta extrai apenas os addons para economizar espaço. Siga o passo a passo abaixo para aplicar as alterações no seu mundo original.

1

📤 Envie seu mundo

Faça upload do arquivo .mcworld ou .zip do seu mundo. A ferramenta vai extrair os addons existentes.

2

✏️ Adicione ou remova addons

Use os botões para adicionar novos addons ou desmarque os que deseja remover da lista de ativação.

3

📥 Baixe o arquivo gerado

O download contém apenas:

  • 📁 behavior_packs/
  • 📁 resource_packs/
  • 📄 world_behavior_packs.json
  • 📄 world_resource_packs.json
4

🔄 Substitua no mundo original

No seu mundo original (descompactado):

  1. Apague as pastas behavior_packs e resource_packs
  2. Apague os arquivos world_behavior_packs.json e world_resource_packs.json
  3. Cole as novas pastas e arquivos gerados pela ferramenta
5

✅ Pronto para jogar!

Após substituir os arquivos, seu mundo está pronto. Não precisa compactar novamente se estiver usando em servidor.

🖥️
Para Servidores Bedrock

A pasta do mundo geralmente fica em:

worlds/Bedrock level/

O nome "Bedrock level" pode variar conforme configurado no server.properties (campo level-name).

Substitua as pastas e arquivos diretamente dentro dessa pasta. Não renomeie para .mcworld — mantenha como pasta normal.

📱
Para Celular/PC (Singleplayer)

Se o mundo veio como .mcworld:

  1. Extraia o .mcworld (é um .zip) para uma pasta
  2. Substitua as pastas e arquivos
  3. Compacte tudo de volta como .zip
  4. Renomeie para .mcworld e importe no jogo
⚠️
Sempre faça backup!

Antes de fazer qualquer alteração, guarde uma cópia do seu mundo original em um local seguro.

❓ Perguntas Frequentes

O que significa “manifest corrompido/incompleto”?

Alguns addons vêm com o arquivo manifest.json fora do padrão: comentários, caracteres inválidos ou mesmo JSON malformado. Este instalador tenta limpar e interpretar o máximo possível, e quando não é viável, cria um placeholder (um manifest genérico) apenas para permitir que você visualize e organize o pack.

Vai funcionar no meu mundo?

Pode funcionar, mas não há garantia. Sempre faça um backup do seu mundo antes de aplicar alterações. Mesmo quando o instalador gera o arquivo de ativação, o Minecraft Bedrock pode recusar o addon se o manifest for inválido para o jogo.

Qual é a forma mais segura de corrigir?

A forma recomendada é ajustar/reativar os addons manualmente pelo cliente do Minecraft Bedrock ou por um gerenciador confiável. Use este instalador como apoio para organizar, identificar problemas e gerar arquivos de ativação, mas valide tudo no jogo.
